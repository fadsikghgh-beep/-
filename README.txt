ПОЛОВЫЕ МОНСТРЫ — обновлённая версия сайта Discord-сервера

Что добавлено:
- Поиск по каталогу участников.
- Плавное появление карточек и секций при прокрутке.
- Локальный музыкальный плеер: выбери аудиофайл с компьютера.
- Пасхалка: нажми на маскота 👾 пять раз.
- Секретный код: ↑ ↑ ↓ ↓ ← → ← → B A.

Как обновить GitHub Pages:
1. Сохрани резервную копию текущих файлов.
2. В корне репозитория замени index.html, styles.css и script.js этими версиями.
3. Не удаляй папку assets: в ней должны остаться member-1.jpg ... member-5.jpg.
4. Нажми Commit changes и подожди обновления GitHub Pages.

Важно:
- Музыкальный плеер воспроизводит выбранный локальный файл. Он не загружает музыку на сайт и не хранит её для посетителей.
- Каталог участников остаётся статическим: сайт не подключён к Discord API, поэтому статусы участников не обновляются автоматически.
- Если хочешь, чтобы у всех посетителей была одна и та же музыка, её нужно отдельно разместить на хостинге с учётом авторских прав и добавить ссылку на аудиофайл.
- При желании можно изменить Discord-приглашение в index.html.


ОБЩИЙ МУЗЫКАЛЬНЫЙ ПЛЕЙЛИСТ
В папке assets/music лежат три MP3-файла, а в script.js прописаны пути к ним.
Загрузи содержимое этой папки на GitHub вместе с обновлёнными index.html,
styles.css и script.js. Не удаляй свою старую папку assets с фотографиями
участников: просто добавь в неё папку music.
Музыка не стартует автоматически (ограничение браузеров): посетитель нажимает
на трек или кнопку воспроизведения. Плейлист и сами треки одинаковые у всех.
