ПОЛОВЫЕ МОНСТРЫ — статический сайт Discord-сервера

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как изменить:
- Участники и тексты: index.html
- Оформление: styles.css
- Аватарки: папка assets (member-1.jpg ... member-5.jpg)
- Пригласительная ссылка Discord сейчас установлена: https://discord.gg/sW3k2eWvD

Сайт не подключён к Discord API: каталог участников статический, а кнопки ведут по приглашению.
Аватарки вырезаны из присланных скриншотов профилей.
